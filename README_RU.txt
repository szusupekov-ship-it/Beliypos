BELIY POS DEMO
===============

Демонстрационное Android-приложение для проверки обнаружения NFC.

ВАЖНО:
- Это НЕ банковский терминал.
- Приложение НЕ принимает платежи и НЕ списывает деньги.
- Приложение не читает и не сохраняет UID карты, номер карты или платёжные данные.
- На экране постоянно указано DEMO ONLY.

КАК ОТКРЫТЬ:
1. Распакуй ZIP на компьютере.
2. Установи Android Studio.
3. Выбери File -> Open и укажи папку BeliyPOS_DEMO.
4. Дождись Gradle Sync.
5. Подключи Android-телефон с включённой отладкой по USB.
6. Нажми Run.

Проверка на телефоне:
- Включи NFC в настройках Android.
- Запусти приложение.
- Поднеси совместимую NFC-метку или карту к задней части телефона.
- При обнаружении приложение покажет сообщение о DEMO-обнаружении.

Примечание:
Некоторые банковские карты могут не обнаруживаться в режиме чтения Android.
Это зависит от карты и устройства. Не используй чужие карты без разрешения.


СБОРКА APK ОНЛАЙН ЧЕРЕЗ GITHUB ACTIONS:
1. Создай новый публичный или приватный репозиторий на github.com.
2. Загрузи в репозиторий ВСЕ файлы и папки из этой папки (включая скрытую папку .github).
3. Открой вкладку Actions в репозитории.
4. Если GitHub спросит разрешение на запуск workflows, разреши.
5. Открой workflow "Build Beliy POS DEMO APK" и нажми Run workflow.
6. Дождись зелёной галочки у завершённого запуска.
7. Открой запуск и скачай artifact "BeliyPOS-DEMO-APK".
8. Распакуй скачанный artifact ZIP — внутри будет app-debug.apk.
9. Перенеси APK на телефон и установи его. Android может попросить разрешить установку из этого источника.

Сборка выполняется на серверах GitHub. Android Studio на компьютере или телефоне не нужна.
